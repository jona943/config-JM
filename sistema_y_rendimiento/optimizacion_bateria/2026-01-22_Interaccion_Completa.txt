# Resumen de Interacción Completa - Optimización de Batería y CPU (22 de enero de 2026)

Este documento resume la conversación y los pasos técnicos realizados para optimizar el consumo de batería en un portátil con Ubuntu Server, XFCE, CPU AMD A9-9425 y 12GB de RAM.

---

### **Fase 1: Primera Herramienta de Optimización - `powertop`**

1.  **Objetivo Inicial:** Optimizar la duración de la batería del portátil.
2.  **Herramienta Propuesta:** Se sugirió `powertop` como herramienta inicial para analizar y ajustar el consumo de energía.
3.  **Instalación y Calibración:**
    *   Se instaló `powertop` mediante el comando `sudo apt update && sudo apt install -y powertop`.
    *   Se calibró la herramienta con `sudo powertop --calibrate` para que obtuviera mediciones precisas del hardware del sistema.
4.  **Automatización de `powertop`:**
    *   Se exploró el modo interactivo y el comando `sudo powertop --auto-tune` para aplicar todas las optimizaciones recomendadas.
    *   Para hacer los cambios permanentes, se creó un servicio de `systemd` (`powertop.service`) que ejecutaría `powertop --auto-tune` en cada arranque del sistema.

---

### **Fase 2: Transición a una Herramienta Más Avanzada - `TLP`**

1.  **Debate y Decisión:** Se planteó la existencia de `TLP` como una alternativa más potente y de tipo "instalar y olvidar". Se explicó que `powertop` es excelente para diagnosticar, mientras que `TLP` es superior para la gestión automática y agresiva del ahorro de energía.
2.  **Decisión del Usuario:** Se acordó que `TLP` era la opción ideal.
3.  **Instalación de `TLP` y Limpieza:**
    *   Se desactivó y detuvo el servicio de `powertop` creado previamente para evitar conflictos (`sudo systemctl disable --now powertop.service`).
    *   Se instaló TLP junto a su extensión para dispositivos de radio con `sudo apt install -y tlp tlp-rdw`.
    *   Se activó el servicio de TLP para que se inicie en cada arranque.
4.  **Primera Documentación:** Se creó el archivo `2026-01-22_Optimizacion_Bateria.txt` resumiendo estos pasos.

---

### **Fase 3: Consulta sobre la Frecuencia del CPU**

1.  **Pregunta del Usuario:** Se consultó cómo revisar la frecuencia del procesador y cuál sería la frecuencia máxima recomendada para configurar.
2.  **Análisis del Sistema:**
    *   Se explicó que TLP ya gestiona la frecuencia de forma dinámica.
    *   Se verificó la frecuencia actual de los núcleos (`~1.4 GHz` en reposo).
    *   Se identificó el "gobernador" de frecuencia activo como `schedutil`, el más moderno y eficiente.
3.  **Investigación y Especificaciones:**
    *   Se buscó el modelo de CPU (AMD A9-9425) y se encontraron sus especificaciones: **3.1 GHz de frecuencia base** y **3.7 GHz de frecuencia máxima (Turbo Boost)**.
4.  **Análisis de la Configuración de TLP:**
    *   Tras varios intentos fallidos por problemas de acceso, se logró leer el archivo `/etc/tlp.conf`.
    *   Se descubrió que el archivo no estaba modificado y TLP usaba sus valores por defecto.
    *   Se identificó la configuración clave por defecto: `CPU_BOOST_ON_BAT=0`, lo que significa que TLP **desactiva el Turbo Boost cuando se usa la batería** para un ahorro máximo, pero lo permite cuando el portátil está conectado a la corriente.
5.  **Conclusión sobre la Frecuencia:** Se concluyó que la configuración actual era la ideal, ya que equilibra rendimiento y ahorro de forma automática, y que no era necesario (ni recomendable) establecer una frecuencia máxima manual.
6.  **Última Consulta:** El usuario preguntó si limitar la CPU a 1.7 GHz ralentizaría el sistema para tareas cotidianas. Se le explicó detalladamente que sí, que tendría un impacto negativo notable en la navegación, reproducción de video y desarrollo, y se reforzó la ventaja del sistema dinámico actual.
